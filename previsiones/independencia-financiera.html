Al abrir el dashboard se carga automáticamente el Gist vinculado y después el Excel. El JSON y el Gist incluyen el ahorro, el resto de supuestos y todos los escenarios guardados con sus ajustes de gasto. La lectura automática usa el JSON raw del Gist. El token solo hace falta para guardar cambios en GitHub: no se guarda en el HTML, en localStorage ni dentro del JSON.
